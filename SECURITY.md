# Security

Please report a vulnerability in any Satelit repository or in the API privately to **contact@satelit.md**, not in a public issue. Include the repository, the version and the steps to reproduce. We answer every report.

Never paste an API key into an issue, a pull request or a log. If a key leaked, revoke it in the [console](https://developer.satelit.md/en/console/) and make a new one.
