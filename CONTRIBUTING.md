# Contributing

Thank you for helping. Issues and pull requests are welcome in every repository.

- Open an issue first for a large change, so we can agree on the shape.
- Keep changes small and in the style of the code around them. Add or update tests; the offline tests must pass without network or a key.
- Never commit an API key, a `.env` file or real personal data. Live tests read `SATELIT_API_KEY` from the environment only.
- Questions about the API itself (data, plans, limits): contact@satelit.md or the [docs](https://developer.satelit.md/en/docs/).
